## 2. Deep-Dive Sponsor Forensics & Strategic Hooks

### 2.1 AG Grid ($10,000 Cash Pool — Largest Sponsor Prize)
- **Why AG Grid Spent $10,000 on This Hackathon**: AG Grid is already used by ~90% of the Fortune 500 (including major investment banks and fintechs), and they recently launched **AG Studio** and AI-assisted grid configuration [S4, S16]. On **October 12, 2026**, AG Grid hosted Official Webinar 3 (*"Build a payments dashboard without building a dashboard"*, `https://www.youtube.com/watch?v=LGfG44i1Fj8`) showing how to bind PayPal API transaction responses directly into AG Grid with zero boilerplate [S16].
- **How to Win the $5,000 1st Place AG Grid Prize**: Judge **Sylwia Vargas** (Senior Technical Community Manager at AG Grid & Bryntum) will immediately reject projects that just render a basic 5-column table [S1, S4]. To win, our **PayOps AI Command Center (`F-07`)** uses:
  1. **Live Server-Side / Client-Side Transaction & Dispute Streaming** from PayPal Sandbox (`list_invoices`, `list_disputes`, `list_transactions`).
  2. **Custom Financial Cell Renderers**: Risk-score badges (`GNN Fraud Score`), policy verdict pills (`APPROVED`, `HELD_FOR_APPROVAL`, `BLOCKED_BY_DSL`), and one-click action buttons (`Approve Execution`, `Send Smart Reminder`, `Submit Compelling Evidence`).
  3. **Row Grouping, Aggregations & Integrated Financial Charts**: Grouping receivables by aging bucket (0–30, 31–60, 61–90+ days) and rendering an embedded AG Chart of Days Sales Outstanding (DSO) and Dispute Win Rate.

### 2.2 APIMatic ($3,000 Cash + 3 × 6-Month Business Subscriptions)
- **The Deep PayPal–APIMatic Partnership**: APIMatic is not an arms-length sponsor — PayPal's Developer Experience team (led by judge **Nathaniel Olson**) partnered directly with **APIMatic** (co-founded by judge **Ameer Hassan**) to replace deprecated PayPal v1 SDKs with the new strongly-typed **PayPal Server SDK** (`@paypal/paypal-server-sdk`) and **APIMatic Context Plugins** [S5, S15, S39].
- **Why Webinar 2 (Oct 7, 2026) Is a Major Clue**: In *"Power Your PayPal Hackathon Project with APIMatic Context Plugins"* (`https://youtu.be/zRWixN68tDg`) [S15], APIMatic demonstrated that LLMs trained on the public internet routinely hallucinate deprecated PayPal endpoints, and showed how plugging APIMatic's MCP Context Plugin into Claude Code / Cursor forces deterministic, type-safe SDK calls.
- **How to Win the APIMatic Prize (and Impress Nathaniel Olson + Ameer Hassan)**: Explicitly integrate **APIMatic Context Plugins** during build and runtime validation (`F-09`) so every agent-generated PayPal payload is schema-verified against APIMatic's OpenAPI/SDK definitions before hitting `api-m.sandbox.paypal.com`.

### 2.3 Bryntum ($3,000 Cash Pool)
- **Synergy with AG Grid**: Notice that **Sylwia Vargas** represents community leadership across both AG Grid and Bryntum, alongside Bryntum Founder & CEO **Mats Bryntse** [S1, S7]. While AG Grid owns tabular financial data, **Bryntum Scheduler Pro / Gantt** owns time-based financial operations.
